# Clounada Proxy

CLI-клиент для работы с ИИ-сервисами (ChatGPT, Claude и др.) через кастомную DNS-маршрутизацию **без VPN и прокси-клиентов**.
Мне надоело жить в концепции от vpn к vpn, а по тому рекомендую пользоваться именно таким образом.

## Возможности

- ✅ Доступ к ChatGPT, Claude, GitHub Copilot без VPN
- ✅ Не требует установки дополнительного ПО
- ✅ Работает через файл `hosts` + SNI Proxy
- ✅ Удобный терминальный интерфейс
- ✅ Потоковая передача ответов (текст появляется по мере генерации)

## Как это работает

1. **Файл `hosts`** перенаправляет запросы к определенным доменам (например, `api.openai.com`) на специальный SNI-прокси сервер.
2. **CLI-клиент** отправляет запросы к API как обычно, но OS сама направляет их на прокси.
3. **SNI-прокси** читает домен из TLS-запроса (SNI) и перенаправляет трафик на реальный сервер.
4. **Результат**: вы получаете доступ к сервисам, а они видят IP прокси, а не ваш реальный IP.
